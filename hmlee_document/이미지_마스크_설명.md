# 이미지 마스크가 필요한가?

## 1. 간단한 답변

**이미지 마스크는 선택적(Optional)입니다.**

- 제공하지 않아도 됩니다 → 자동으로 모두 `True`로 설정됩니다
- 제공하면 → 패딩된 이미지를 표시하는 데 사용됩니다

---

## 2. 이미지 마스크란?

### 2.1 정의

이미지 마스크는 **각 이미지가 유효한지(valid) 여부를 나타내는 불리언 텐서**입니다.

```python
img_mask: torch.Tensor  # Shape: (batch_size,)
# True: 유효한 이미지
# False: 패딩된/빈 이미지
```

### 2.2 목적

1. **패딩 처리**: 배치에서 일부 이미지가 없을 때 표시
2. **Attention 마스킹**: 패딩된 이미지 토큰을 attention에서 제외
3. **빈 카메라 처리**: 누락된 카메라 뷰 표시

---

## 3. 코드에서의 사용

### 3.1 `prepare_images` 메서드

```python
def prepare_images(self, batch):
    images = []
    img_masks = []
    
    for key in present_img_keys:
        # 이미지 전처리...
        
        # 마스크 처리
        if f"{key}_padding_mask" in batch:
            # 배치에 마스크가 제공된 경우
            mask = batch[f"{key}_padding_mask"].bool()
        else:
            # 마스크가 제공되지 않은 경우 → 모두 True
            mask = torch.ones(bsize, dtype=torch.bool, device=device)
        
        images.append(img)
        img_masks.append(mask)
    
    # 빈 카메라 처리
    for num_empty_cameras in range(len(missing_img_keys)):
        img = torch.ones_like(img) * -1  # 패딩된 이미지
        mask = torch.zeros_like(mask)    # False 마스크
        images.append(img)
        img_masks.append(mask)
    
    return images, img_masks
```

**핵심 포인트**:
- 마스크가 없으면 → 자동으로 모두 `True` 생성
- 마스크가 있으면 → 제공된 마스크 사용
- 빈 카메라는 → `False` 마스크

### 3.2 `embed_prefix` 메서드에서의 사용

```python
def embed_prefix(self, images, img_masks, ...):
    for img, img_mask in zip(images, img_masks):
        # 이미지 임베딩
        img_emb = self.vlm_with_expert.embed_image(img)
        # Shape: (B, num_patches, hidden_size)
        
        # 마스크 확장: 이미지 레벨 → 패치 레벨
        bsize, num_img_embs = img_emb.shape[:2]
        img_mask = img_mask[:, None].expand(bsize, num_img_embs)
        # Shape: (B, 1) → (B, num_patches)
        
        # 패딩 마스크에 추가
        pad_masks.append(img_mask)
```

**변환 과정**:
```
이미지 레벨 마스크: (B,) - 각 이미지가 유효한지
    ↓ expand
패치 레벨 마스크: (B, num_patches) - 각 패치가 유효한지
    ↓
Attention 마스크에 포함
```

### 3.3 Attention 마스크 생성

```python
def make_att_2d_masks(pad_masks, att_masks):
    # 패딩 마스크로 2D attention 마스크 생성
    pad_2d_masks = pad_masks[:, None, :] * pad_masks[:, :, None]
    # (B, N, N) - i번째 토큰이 j번째 토큰을 볼 수 있는지
    
    att_2d_masks = att_2d_masks & pad_2d_masks
    # 패딩된 토큰은 attention에서 제외
    return att_2d_masks
```

**효과**:
- 패딩된 이미지 토큰(`mask=False`)은 attention 계산에서 제외
- 유효한 이미지 토큰(`mask=True`)만 attention에 참여

## 4. 언제 마스크가 필요한가?

### 4.1 마스크가 필요한 경우

1. **가변 길이 배치**:
   ```python
   # 일부 샘플에 이미지가 없는 경우
   batch = {
       "image_0": [img1, img2],  # 2개 이미지
       "image_1": [img3],        # 1개 이미지만
   }
   # image_1의 두 번째 이미지는 패딩 → 마스크 필요
   ```

2. **빈 카메라 처리**:
   ```python
   # 일부 카메라가 작동하지 않는 경우
   # 해당 이미지는 패딩되고 마스크는 False
   ```

3. **데이터 수집 중 누락**:
   ```python
   # 데이터 수집 중 일부 프레임이 손실된 경우
   # 마스크로 유효한 프레임만 표시
   ```

### 4.2 마스크가 필요 없는 경우

1. **모든 이미지가 유효한 경우**:
   ```python
   # 모든 샘플에 모든 카메라 이미지가 있는 경우
   # 마스크 없이도 자동으로 모두 True로 설정됨
   ```

2. **고정 길이 배치**:
   ```python
   # 배치 내 모든 샘플이 동일한 수의 이미지를 가진 경우
   # 마스크 없이도 정상 작동
   ```

## 5. 마스크 제공 방법

### 5.1 배치에 마스크 포함

```python
batch = {
    "image_0": images,                    # 이미지
    "image_0_padding_mask": masks,        # 마스크 (선택적)
    "image_1": images,
    "image_1_padding_mask": masks,        # 마스크 (선택적)
    # ...
}
```

**마스크 형식**:
```python
mask: torch.Tensor  # Shape: (batch_size,)
# dtype: bool 또는 int (0/1)
# True/1: 유효한 이미지
# False/0: 패딩된 이미지
```

### 5.2 마스크 없이 사용

```python
batch = {
    "image_0": images,  # 마스크 없음
    "image_1": images,  # 마스크 없음
    # ...
}

# 자동으로 모든 이미지에 대해 True 마스크 생성
```

## 6. 실제 사용 예시

### 6.1 마스크 없이 사용 (일반적인 경우)

```python
# 모든 이미지가 유효한 경우
batch = {
    "image_0": torch.randn(4, 3, 224, 224),  # 4개 샘플
    "image_1": torch.randn(4, 3, 224, 224),  # 4개 샘플
}

policy = SmolVLAPolicy(config)
images, img_masks = policy.prepare_images(batch)

# img_masks[0]: tensor([True, True, True, True])  # 자동 생성
# img_masks[1]: tensor([True, True, True, True])  # 자동 생성
```

### 6.2 마스크와 함께 사용 (가변 길이)

```python
# 일부 샘플에 이미지가 없는 경우
batch = {
    "image_0": torch.randn(4, 3, 224, 224),
    "image_0_padding_mask": torch.tensor([True, True, False, True]),
    # 3번째 샘플의 이미지는 패딩
}

policy = SmolVLAPolicy(config)
images, img_masks = policy.prepare_images(batch)

# img_masks[0]: tensor([True, True, False, True])  # 제공된 마스크 사용
```

### 6.3 빈 카메라 처리

```python
# image_1이 배치에 없는 경우
batch = {
    "image_0": torch.randn(4, 3, 224, 224),
    # image_1 없음
}

config.empty_cameras = 1  # 빈 카메라 1개 허용

policy = SmolVLAPolicy(config)
images, img_masks = policy.prepare_images(batch)

# images[0]: 실제 이미지
# images[1]: 패딩된 이미지 (torch.ones * -1)
# img_masks[0]: tensor([True, True, True, True])
# img_masks[1]: tensor([False, False, False, False])  # 빈 카메라
```

## 7. 마스크의 영향

### 7.1 Attention 계산

```python
# 패딩된 이미지 토큰은 attention에서 제외됨
# → 계산 효율성 향상
# → 패딩 토큰이 예측에 영향을 주지 않음
```

### 7.2 Loss 계산

이미지 마스크는 직접적으로 loss 계산에 영향을 주지 않지만, attention을 통해 간접적으로 영향을 줍니다.

## 8. 요약

### 이미지 마스크가 필요한가?

**아니요, 선택적입니다.**

### 언제 제공해야 하나?

1. ✅ **가변 길이 배치**: 일부 샘플에 이미지가 없는 경우
2. ✅ **빈 카메라**: 일부 카메라가 작동하지 않는 경우
3. ✅ **데이터 누락**: 수집 중 일부 프레임이 손실된 경우

### 언제 제공하지 않아도 되나?

1. ✅ **모든 이미지 유효**: 모든 샘플에 모든 이미지가 있는 경우
2. ✅ **고정 길이 배치**: 배치 내 모든 샘플이 동일한 구조인 경우

### 기본 동작

- 마스크가 없으면 → **자동으로 모두 `True` 생성**
- 마스크가 있으면 → **제공된 마스크 사용**
- 빈 카메라는 → **자동으로 `False` 마스크**

---

## 9. 결론

**이미지 마스크는 선택적 기능입니다.**

- 대부분의 경우 마스크 없이도 정상 작동합니다
- 특수한 경우(가변 길이, 빈 카메라 등)에만 마스크를 제공하면 됩니다
- 코드가 자동으로 처리하므로 걱정할 필요가 없습니다

**권장사항**:
- 일반적인 사용: 마스크 제공 불필요
- 특수한 경우: 마스크 제공 권장 (정확성 향상)
