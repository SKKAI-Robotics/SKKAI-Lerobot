# Aloha란 무엇인가?

## 1. Aloha 개요

**Aloha (A Low-cost Open-source Hardware for Autonomous manipulation)**는 MIT에서 개발한 **저비용 오픈소스 로봇 조작 하드웨어 및 소프트웨어 플랫폼**입니다.

### 핵심 특징

- **양팔 로봇 시스템** (Dual-arm robot)
- **텔레로봇팔** (Telerobotic arm): 사용자의 움직임을 모방하여 작업 수행
- **저비용**: 연구용 로봇으로 접근 가능한 가격
- **오픈소스**: 하드웨어 설계와 소프트웨어가 모두 공개됨

---

## 2. Aloha의 목적

### 2.1 로봇 학습 데이터 수집

Aloha의 주요 목적은 **로봇 조작 학습을 위한 데이터를 효율적으로 수집**하는 것입니다:

1. **텔레조작 (Teleoperation)**: 
   - 사용자가 마스터 로봇팔을 조작
   - 슬레이브 로봇팔이 동일한 움직임을 반복
   - 이 과정에서 (관찰, 액션) 쌍 데이터 수집

2. **데모 데이터 생성**:
   - 인간 전문가의 조작을 기록
   - Imitation Learning을 위한 고품질 데이터셋 생성

### 2.2 연구 플랫폼

- 로봇 조작 알고리즘 연구
- Vision-Language-Action (VLA) 모델 학습
- 다양한 조작 태스크 실험

## 3. Aloha 하드웨어 구성

### 3.1 로봇팔 구조

```
Aloha 로봇 = 2개의 로봇팔 (왼쪽 + 오른쪽)
```

각 팔의 구성:
- **7개의 관절** (7-DOF: Degrees of Freedom)
- **그리퍼** (Gripper)
- **총 14개 관절 + 2개 그리퍼 = 16차원 액션/상태 공간**

### 3.2 관절 인덱스 구조

```
왼쪽 팔:
  - 관절 0-6: 7개 관절
  - 그리퍼 6: 왼쪽 그리퍼

오른쪽 팔:
  - 관절 7-13: 7개 관절  
  - 그리퍼 13: 오른쪽 그리퍼
```

### 3.3 센서

- **카메라**: 작업 공간 관찰
- **관절 인코더**: 각 관절의 위치/속도 측정
- **그리퍼 센서**: 그리퍼 위치 측정

---

## 4. Aloha의 액션/상태 표현

### 4.1 액션 공간

```python
action = [
    # 왼쪽 팔 관절 (7개)
    joint_0, joint_1, joint_2, joint_3, joint_4, joint_5, joint_6,
    # 왼쪽 그리퍼
    gripper_left,
    # 오른쪽 팔 관절 (7개)
    joint_7, joint_8, joint_9, joint_10, joint_11, joint_12, joint_13,
    # 오른쪽 그리퍼
    gripper_right
]
# 총 16차원
```

### 4.2 상태 공간

상태는 관절 위치, 속도, 그리퍼 위치 등을 포함합니다.

### 4.3 그리퍼 표현

Aloha는 그리퍼를 **선형 위치**로 표현합니다:

```python
# Aloha 그리퍼 값 (정규화 전)
gripper_open = 0.01844  # 미터 (열림)
gripper_closed = 0.05800  # 미터 (닫힘)

# Aloha 그리퍼 조인트 값 (정규화 후)
gripper_joint_open = -0.6213
gripper_joint_close = 1.4910
```

## 5. Aloha와 SmolVLA의 관계

### 5.1 왜 변환이 필요한가?

SmolVLA는 **다른 형식**으로 액션과 상태를 표현합니다:

1. **조인트 방향**: 일부 조인트의 부호가 반대
2. **그리퍼 표현**: 
   - Aloha: 선형 위치 (미터)
   - SmolVLA: 각도 (라디안)

### 5.2 변환의 목적

`adapt_to_pi_aloha=True` 설정 시:
- Aloha 로봇에서 수집한 데이터로 SmolVLA 학습 가능
- SmolVLA 모델을 Aloha 로봇에서 직접 실행 가능

## 6. Aloha 사용 예시

### 6.1 데이터 수집

```python
# Aloha 로봇으로 데모 데이터 수집
# - 텔레조작으로 작업 수행
# - (관찰, 액션) 쌍 기록
```

### 6.2 모델 학습

```python
# Aloha 데이터로 SmolVLA 학습
config = SmolVLAConfig(
    adapt_to_pi_aloha=True,  # Aloha 변환 활성화
)

policy = SmolVLAPolicy(config)
# Aloha 형식 데이터로 학습
```

### 6.3 로봇 실행

```python
# Aloha 로봇에서 SmolVLA 실행
action = policy.select_action(observation)
# 자동으로 Aloha 형식으로 변환되어 로봇에 전송
```

## 7. Aloha의 장점

### 7.1 접근성

- **저비용**: 연구용 로봇으로 접근 가능
- **오픈소스**: 커뮤니티 기반 개발
- **쉬운 구축**: 상세한 하드웨어 설계 제공

### 7.2 데이터 수집 효율성

- **텔레조작**: 전문가의 움직임을 직접 기록
- **고품질 데이터**: 실제 작업 수행 데이터
- **다양한 태스크**: 다양한 조작 작업 지원

### 7.3 연구 활용

- **표준 플랫폼**: 많은 연구에서 사용
- **벤치마크**: 성능 비교 기준
- **재현성**: 동일한 하드웨어로 실험 재현

## 9. Aloha vs 다른 로봇 플랫폼

### 9.1 특징 비교

| 특징 | Aloha | 다른 로봇 |
|------|-------|----------|
| 팔 개수 | 2개 (양팔) | 1개 또는 2개 |
| 비용 | 저비용 | 다양함 |
| 오픈소스 | 예 | 일부만 |
| 텔레조작 | 지원 | 다양함 |
| 연구 사용 | 널리 사용 | 다양함 |

### 9.2 Aloha의 독특한 점

- **양팔 협조 작업**: 두 팔을 동시에 사용한 복잡한 작업
- **텔레조작 특화**: 데이터 수집에 최적화
- **커뮤니티**: 활발한 오픈소스 커뮤니티

## 10. 요약

### Aloha란?

**MIT에서 개발한 저비용 오픈소스 양팔 로봇 플랫폼**

### 주요 특징:

1. **양팔 시스템**: 2개의 7-DOF 로봇팔
2. **텔레조작**: 사용자 움직임 모방
3. **데이터 수집**: 로봇 학습을 위한 고품질 데이터
4. **오픈소스**: 하드웨어/소프트웨어 공개

### SmolVLA와의 관계:

- Aloha는 **하드웨어 플랫폼**
- SmolVLA는 **AI 모델**
- `adapt_to_pi_aloha` 변환으로 **호환성 확보**

### 사용 목적:

- 로봇 조작 연구
- VLA 모델 학습
- 실제 로봇 제어

Aloha는 로봇 조작 연구와 학습을 위한 **접근 가능하고 실용적인 플랫폼**입니다!
